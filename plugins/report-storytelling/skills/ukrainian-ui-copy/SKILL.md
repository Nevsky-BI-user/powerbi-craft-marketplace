# Ukrainian UI copy — граматика рядків, які збирає код

## Overview

Рядки, які склеює код, — єдине місце, де українська ламається **тихо**: типи
компілюються, тести зелені, а на екрані «порівняння з червень». Компілятор не
знає відмінків. Цей скіл володіє граматикою згенерованого тексту; що саме
текст стверджує — `data-storytelling`, як він виглядає — `pbi-typography`.

## When to Use

- Шаблонний рядок з місяцем, числом, назвою підприємства чи одиницею.
- Підпис після прийменника; множина після числа; різниця двох відсотків.
- Симптоми: «до червень», «1 підприємств», «−3%» там, де мають бути пункти.

**NOT for:** формати чисел/дат у візуалах (`pbi-typography`), формулювання
висновку (`data-storytelling`), «розлюднення» тексту (`humanizer`), переклад
документів.

## Quick Reference — пастка → правило → перевірка

| Пастка | Правило | Перевірка |
|---|---|---|
| Місяць після прийменника | називний — лише самостійно | у коді нема `MONTH_FULL[i]` одразу після «до/з/у/за» |
| «до …», «з початку …» | **родовий**: до червня | |
| «у …», «в …» | **місцевий**: у липні | |
| «з …» (разом із) | **орудний**: з червнем | |
| Множина після числа | три форми, за останніми цифрами | 1 / 2 / 5 / 11 / 21 дають різні гілки |
| Різниця двох відсотків | **п.п.**, не % | «−3 п.п. до червня», не «−3%» |
| Назва в лапках | не відмінювати всередині лапок | «по ГК "Нафтогаз України"» |
| Перевірка лише `tsc` + тестами | граматика не типізується | відкрити превʼю і прочитати очима |

## Відмінки місяців (повна таблиця)

```
наз.  січень лютий  березень квітень травень червень липень серпень вересень жовтень листопад грудень
род.  січня  лютого березня  квітня  травня  червня  липня  серпня  вересня  жовтня  листопада грудня
місц. січні  лютому березні  квітні  травні  червні  липні  серпні  вересні  жовтні  листопаді грудні
оруд. січнем лютим  березнем квітнем травнем червнем липнем серпнем вереснем жовтнем листопадом груднем
```

Тримати їх масивами поруч (`MONTH_FULL`, `MONTH_GEN`, …), а не схиляти на льоту.

## Множина після числа

```ts
/** 1 підприємство · 2 підприємства · 5 підприємств */
export function plural(n: number, one: string, few: string, many: string): string {
  const d10 = n % 10;
  const d100 = n % 100;
  if (d10 === 1 && d100 !== 11) return one;
  if (d10 >= 2 && d10 <= 4 && (d100 < 12 || d100 > 14)) return few;
  return many;
}
```

Тест-вектори, які ловлять усі три гілки і винятки-підступи:
`1→one · 2→few · 5→many · 11→many · 21→one · 22→few · 25→many · 111→many · 112→many`.

## Найдешевший обхід — перефразувати в називний

Перш ніж заводити ще одну таблицю відмінків, спробуйте зняти прийменник:

```
було:  `порівняння з ${MONTH_FULL[i]}`      → «з червень»   ✗
стало: `база порівняння — ${MONTH_FULL[i]}` → «база порівняння — червень» ✓
було:  `Найбільше розривів — у ${MONTH_FULL[i]}` → «у липень» ✗
стало: `Найбільше розривів: ${MONTH_FULL[i]} — …`               ✓
```

Там, де прийменник несе зміст («−3 п.п. **до червня**»), беріть `MONTH_GEN`.

## Common Mistakes

| Помилка | Чому погано | Правильно |
|---|---|---|
| `${MONTH_FULL[i]}` після прийменника | «до червень» — читач бачить недбалість у першому ж рядку | `MONTH_GEN[i]` або перефразувати |
| `${n} підприємств` без гілок | «1 підприємств» | `plural(n, …)` |
| «−3%» для різниці відсотків | читач множить різницю ще раз на базу | «−3 п.п.» |
| Схиляння назви в лапках | «ГК "Нафтогазу України"» — юридична назва змінена | лапки лишаються недоторканими |
| Термін-синонім «на льоту» | «підрозділ» замість «підприємство» = інший обʼєкт | глосарій проєкту, один термін на поняття |
| «Зелений tsc = готово» | відмінок і множина не типізуються | прочитати рядок у превʼю |

## Verify before done

Перелічити ВСІ шаблонні рядки в зміні → кожен прийменник має свій відмінок →
множина перевірена на 1/2/5/11/21 → різниці відсотків у п.п. → сторінка
відкрита в превʼю і прочитана очима, а не лише зібрана компілятором.
