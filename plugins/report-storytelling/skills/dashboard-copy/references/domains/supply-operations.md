# Логістика, постачання і виробництво — EN → UA для дашбордів і звітів

Домен покриває закупівлі, склад, транспорт, виробництво, якість,
обслуговування обладнання й охорону праці.

## Як користуватися

- Обсяги — у тоннах, кубометрах, штуках або палетах; одиниця в підписі.
- Показники надійності (вчасність, якість) — у відсотках, різниця — у **в. п.**
- Час у процесах — у годинах або днях; який саме інтервал вимірюємо, каже
  підпис або підказка.

## 5. Кальки й пастки

| Не пиши | Пиши |
|---|---|
| поставка | постачання (процес), партія (обсяг) |
| поставщик | постачальник |
| закупка | закупівля |
| відгрузка | відвантаження |
| простой | простій |
| наладка | налагодження |
| брак виробу «зашкалює» | частка браку — 7%, це вище норми |
| виробіток | виробіток (норма) або випуск (обсяг) — розрізняти |
| пробіг машин | пробіг транспорту |
| логістичні витрати виросли на 3% | зросли на 3 в. п. — якщо це частка |
| склад завантажений на 90 відсотків | завантаженість складу — 90% |
| комплектація замовлення | комплектування замовлення |
| відходи утилізовано | відходи перероблено або знешкоджено — назвати спосіб |
| нещасний випадок без наслідків | небезпечна подія без наслідків |
