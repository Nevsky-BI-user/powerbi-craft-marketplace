# Формати чисел і дат — джерело істини: CLDR `uk`

Усі правила нижче взяті з Unicode CLDR (локаль `uk`) — саме ці дані емітить
`Intl.NumberFormat('uk-UA')` / `Intl.DateTimeFormat('uk-UA')` у браузері й
Node. Де CLDR мовчить, наведено українську норму (ДСТУ, правопис).

## Числа

| Що | Правило | Приклад |
|---|---|---|
| Десятковий роздільник | кома | `12,4` |
| Роздільник розрядів | **нерозривний пробіл U+00A0** (не звичайний пробіл, не крапка) | `1 234 567` |
| Форматер у коді | лише `Intl.NumberFormat('uk-UA', …)` / `toLocaleString('uk-UA')`; у тестах і regex очікуй U+00A0 | `new Intl.NumberFormat('uk-UA',{maximumFractionDigits:1}).format(3.8)` → `3,8` |
| Відсоток | без пробілу перед `%` (CLDR: `#,##0%`) | `12,3%` |
| Різниця двох відсотків | **«в. п.»** — відсоткові пункти (так пише НБУ; «п.п.»/«пп.» у словниках = «пункти») | `−3 в. п. до червня` |
| Скорочення великих чисел | `тис.` **з крапкою**; `млн`, `млрд`, `трлн` **без** (CLDR compact: `0 тис'.'`, `0 млн`) | `12,4 млн грн`, `850 тис.` |
| Валюта | код `грн` після числа через нерозривний пробіл; символ `₴` — лише там, де тісно (CLDR: `#,##0.00 ¤`) | `1 250 грн` |
| Число ↔ одиниця | нерозривний пробіл, щоб пара не розривалася на межі рядка | `5 осіб`, `12 млн грн` |
| Від'ємне число | знак мінус U+2212, не дефіс і не тире | `−5,1%` |
| Діапазон | тире (en dash U+2013) без пробілів | `2024–2026`, `0–5` |
| Округлення для порівнянь | дві значущі цифри; надлишкова точність — шум (ONS) | `37 із 45 (82%)` |
| Вирівнювання | числа в колонках — по правому краю, табличні цифри (`tabular-nums`) | |

## Дати й час

| Що | Правило | Приклад |
|---|---|---|
| Штамп дати | `дд.ММ.рррр` з нулями (ДСТУ 4163:2020) | `02.09.2026` |
| Коротка дата CLDR | `dd.MM.yy` | `02.09.26` |
| Довга дата CLDR | `d MMMM y 'р'.` — місяць у **родовому** | `2 вересня 2026 р.` |
| Час | 24-годинний `HH:mm` | `09:00` |
| Штамп оновлення на дашборді | дієприкметник + дата | `Оновлено 02.09.2026` |

## Назви місяців — два набори (CLDR `stand-alone` / `format`)

| | Самостійно (вісь, заголовок, слайсер) — називний | У даті / після прийменника — родовий | Скорочено (з крапкою) |
|---|---|---|---|
| 1 | січень | січня | січ. |
| 2 | лютий | лютого | лют. |
| 3 | березень | березня | бер. |
| 4 | квітень | квітня | квіт. |
| 5 | травень | травня | трав. |
| 6 | червень | червня | черв. |
| 7 | липень | липня | лип. |
| 8 | серпень | серпня | серп. |
| 9 | вересень | вересня | вер. |
| 10 | жовтень | жовтня | жовт. |
| 11 | листопад | листопада | лист. |
| 12 | грудень | грудня | груд. |

Позначка на осі — самостійна форма («Червень»); у реченні з прийменником —
родовий («до червня»); скорочення бери з таблиці, не вигадуй («Лип» — ні,
«лип.» — так).
