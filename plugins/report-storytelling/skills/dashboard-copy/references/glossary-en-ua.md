# Словник EN → UA для дашбордів (115 термінів, з джерелами)

Колонка «Microsoft UA»: **✓** — з людсько-локалізованих сторінок
support.microsoft.com/uk-ua (це і є термінологічна база Microsoft);
**MT** — лише з машинно перекладеної сторінки learn.microsoft.com/uk-ua
(**не копіювати**); **—** — не перевірено (Language Portal недоступний).
Колонка «Ділова українська» — що писати в підписі для нетехнічного читача.

## Ієрархія джерел термінології

1. Людсько-локалізовані сторінки Microsoft (Excel/Power Pivot UA).
2. Українські регулятори й норми: НП(С)БО 1 (назви статей фінзвітності),
   Держстат (Інструкція № 286 — кількість працівників), НБУ (звіти).
3. Фахове вживання в Україні (HR-платформи, банки, курси Power BI).
4. Машинний переклад Microsoft — **ніколи** (там Fabric = «Тканина»,
   dashboard = «приладна дошка»).

## Лишаються латиницею

KPI · eNPS · NPS · EBITDA · 9-box · DAX · YTD (лише де тісно; інакше
«з початку року») · ROI · CRM · ERP. Усе інше — українською.
