Підказка: титул, нічого не клікати. Обіцянка: за 10 хвилин шаблон покаже, як гортати, друкувати й вести доповідь. Позначка 0:30.

Дві частини за 10 хвилин

Частина 1 не потребує технічної підготовки

Назвати дві частини. Діапазони слайдів рахує рушій. Позначка 1:00.

Як показати з будь-якого екрана?

Пауза. Спитати, хто показував із чужого ноутбука. Позначка 1:15.

Показ · модель

Канва масштабується без обрізання

Одна схема: канва, коефіцієнт, екран. Рамка слайда завжди цілком на екрані, від телефона до проектора. Перехід: «Як це виглядає для доповідача, покаже демо». Позначка 2:15.

Демо

Вікно доповідача йде слідом

Натиснути S, перетягнути вікно доповідача на свій екран, гортати стрілками. Дивитися на те, що обидва вікна показують один слайд. Жорстка зупинка на 4:15. Якщо вікно не відкрилося, показати наступний слайд. Позначка 4:15.

Показ · результат

Нотатки й таймер видно лише доповідачу

Демо

Нотатки змінюються разом зі слайдом

Що помітити: нотатки внизу ліворуч змінюються разом зі слайдом. Позначка 4:45.

Показ · підсумок демо

Три клавіші ведуть увесь показ

  1. S відкриває вікно доповідача
  2. Стрілки гортають обидва вікна
  3. O показує всі слайди

Назвати три кроки вголос. Решта клавіш у додатку. Перехід до друку. Позначка 5:15.

Що потрапляє в PDF?

Друга частина: PDF, який розсилають після доповіді. Позначка 5:30.

Друк · огляд

Друк тримається на трьох правилах

  • Канва 1280×720 стає сторінкою
  • Кнопки, панель і нотатки сховано
  • Темна тема не псує друк

Три картки зліва направо. Перше правило розберемо, решта очевидні. Позначка 6:30.

Кожен слайд стає окремою сторінкою

    • Сторінка дорівнює канві, без полів
    • дають стільки ж сторінок
    CSS
    @page { size: 1280px 720px; margin: 0 }
.slide { break-after: page }

    Показати рядок CSS і кнопку копіювання. У PDF кнопки немає. Позначка 7:30.
