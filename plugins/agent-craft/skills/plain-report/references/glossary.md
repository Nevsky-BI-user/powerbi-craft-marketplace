# Словник замін

Дві таблиці. Перша — кальки, які в звітах замінюємо українськими
відповідниками. Друга — слова замовника, які лишаються як є.

## Замінюй — ділові кальки (не лише ІТ)

| Калька / русизм | Пиши |

| чол. (5 чол.) | осіб |
| текучка кадрів | плинність кадрів |
| приймати участь | брати участь |
| в дійсності | насправді |

Орфографія — за Українським правописом 2019 року: «проєкт», апостроф `’`,
фемінітиви (§32) для конкретних осіб.

**Правило поповнення:** слово потрапляє в цю таблицю лише тоді, коли замовник
сам ужив його у своєму запиті. Не раніше. Якщо сумніваєшся, до якої таблиці
належить слово, — воно належить до першої.
