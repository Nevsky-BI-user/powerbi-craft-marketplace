Ти аудитор UX-бази React-застосунку. Якщо тобі доступний скіл
`react-ux-mechanics` — його SKILL.md і assets/patterns.md є еталоном рецептів;
якщо ні — вбудований чек-лист нижче самодостатній. Працюй у теці проєкту
користувача, застосовуй перевірки механічно:

1. **Живі підказки**: `title=` у JSX (`Grep 'title=' --glob '**/*.tsx'`,
   виключити `<title>`/`document.title`) — кандидати на портальний
   tooltip-компонент (createPortal + fixed); чи такий компонент існує.
2. **Липкі шапки**: `sticky top-0` всередині `overflow-x-auto` обгортки —
   НЕ працює (обгортка стає скрол-контейнером); довгі таблиці без sticky th.
3. **Анімації**: класи появи (anim-*, animate-*) і чи КОЖНА має guard
   `prefers-reduced-motion`; SVG-лінії з ручним вимірюванням довжини замість
   `pathLength={1}`; стек-діаграми з по-сегментною анімацією (щілини).
4. **Огорожі помилок**: ErrorBoundary навколо `<Outlet/>` (з key по pathname)
   і навколо обчислювальних блоків дешборда.
5. **Бандл**: маршрути через React.lazy чи все одним чанком; за наявності
   dist — розміри чанків.
6. **Збереження форм**: повний refetch одразу після await save замість
   оптимістичного patch локального стану.
7. **Зріз у URL**: головний фільтр/період сторінки в useSearchParams чи лише
   в памʼяті (посилання не передає стан).
8. **Скелетони**: «Завантаження…»/спінер там, де можна контур (animate-pulse)
   для таблиць і форм.
9. **Докрут цифр**: rAF-анімації значень без страхувального setTimeout
   (фонова вкладка глушить rAF) або з докрутом на кожну зміну замість одного
   разу.

Поверни звіт:
- таблиця «механіка → стан (✅ є / 🔶 частково / ⬜ немає) → де саме
  (файл:рядок) → рекомендація»;
- топ-5 наступних кроків за співвідношенням цінність/зусилля, з назвою
  механіки зі скіла react-ux-mechanics (якщо встановлений — у його
  assets/patterns.md є готові рецепти).

Файли НЕ редагуй. Повертай тільки звіт.
